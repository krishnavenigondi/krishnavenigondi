### 🤖 AI-Powered Serverless Error Analysis System
> *Turning noisy logs into actionable intelligence — automatically.*

A production-grade serverless system that ingests application error logs, performs AI-driven root cause analysis, and returns automated fix recommendations — all without a single server to manage.

**Architecture:** `API Gateway` → `Cognito Auth` → `Lambda` → `Amazon Bedrock (Claude)` → `Structured Insights`

**Key highlights:**
- Serverless-first design — zero infrastructure to maintain
- AI root cause analysis using **Amazon Bedrock** foundation models
- Secure access via **Amazon Cognito** with JWT authentication
- Response includes probable cause, affected component, and suggested fix

### 🏛️ AWS Landing Zone — 32-Account Governance Framework
> *Enterprise-grade cloud governance, built for scale and security.*

Architected a complete AWS Landing Zone for a global enterprise client, enabling secure, auditable, and cost-tracked operations across 32 AWS accounts in a multi-region environment.

**Key components built:**
- **Account vending** via AWS Organizations + OU structure
- **SCPs** enforcing security guardrails (deny root, MFA enforcement, region restrictions)
- **Cross-account IAM roles** with Permission Boundaries and least-privilege access
- **Lambda tagging automation** for mandatory cost allocation compliance
- **CloudWatch cross-account observability** with ServiceNow alerting integration
- **CI/CD pipeline** via Terraform + CloudFormation StackSets + GitHub Actions
